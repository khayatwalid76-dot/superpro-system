# SUPER_PRO SYSTEM - نظام إدارة الشركة المتكامل

نظام إدارة متكامل باللغة العربية للشركات الصغيرة والمتوسطة، مع واجهة عصرية وتصميم متجاوب.

## ✨ **المميزات الرئيسية**

### 🎯 **الإدارة الأساسية**
- **شؤون الموظفين** - إدارة كاملة للموظفين مع بيانات الإقامة والرواتب
- **إدارة العملاء** - قاعدة بيانات عملاء متكاملة
- **إدارة العقود** - تتبع العقود وتنبيهات الانتهاء + تصفية حسب الشهر (جديد)
- **الحضور والانصراف** - نظام تسجيل الحضور اليومي

### 💰 **الإدارة المالية**
- **المدخولات اليومية** - تسجيل وتتبع الإيرادات
- **المصروفات اليومية** - إدارة المصاريف والتكاليف
- **الحسابات المالية** - تقارير مالية شاملة
- **الرواتب** - حساب وتوزيع الرواتب

### 📅 **التخطيط والمهام**
- **التقويم** - تنظيم المواعيد والأحداث
- **لوحة المهام** - إدارة وتتبع المهام اليومية
- **العمل اليومي** - تسجيل وتوزيع الأعمال

### 📊 **التقارير والتحليل**
- **تقارير متقدمة** - رسوم بيانية تفاعلية
- **تصدير البيانات** - Excel و PDF
- **إحصائيات حية** - لوحة تحكم شاملة

### 🤖 **الميزات الذكية (جديد في v2.5)**
- **التحليلات المتقدمة** - ROI والاتجاهات والتنبؤات
- **بوابة الدفع** - Stripe, PayPal, Apple Pay, Google Pay, Fawry
- **الذكاء الاصطناعي** - التنبؤ بالطلب وتحليل المشاعر والتوصيات
- **اكتشاف الشذوذ** - كشف الاحتيال والقيم غير الطبيعية

### 🌟 **مميزات إضافية**
- **البحث الفوري** - بحث سريع في جميع البيانات
- **الإشعارات الذكية** - تنبيهات تلقائية للمهام المهمة
- **التخزين السحابي** - مزامنة تلقائية مع Firebase (مع مفاتيح حقيقية!)
- **الوضع الليلي** - واجهة مريحة للعين
- **دعم الموبايل** - تصميم متجاوب بالكامل

## 🚀 **التثبيت والتشغيل**

### الطريقة الأولى: Netlify (موصى به)
1. قم بإنشاء حساب على [Netlify](https://netlify.com)
2. ارفع المشروع عبر Git أو السحب والإفلات
3. سيتم نشر الموقع تلقائياً

### الطريقة الثانية: GitHub Pages
1. ارفع المشروع إلى GitHub
2. اذهب إلى Settings > Pages
3. اختر Source: Deploy from a branch
4. اختر main branch و gh-pages
5. سيتم نشر الموقع على `https://username.github.io/repository-name`

### الطريقة الثالثة: استضافة محلية
1. قم بتنزيل المشروع
2. استخدم أي خادم محلي (Live Server, XAMPP, etc.)
3. افتح `index.html` في المتصفح

## 🔧 **التخصيص**

### تغيير الألوان
عدل متغيرات CSS في `:root`:
```css
:root {
    --primary: #2c3e50;
    --secondary: #3498db;
    --success: #28a745;
    --danger: #dc3545;
}
```

### إضافة حقول جديدة
1. عدل في `app.js` دوال البيانات
2. أضف حقول HTML في `index.html`
3. حدّث دوال الحفظ والتحميل

## 📈 **الأداء**

- **تحميل سريع** - أقل من 3 ثوانٍ
- **حجم صغير** - أقل من 500KB
- **ذاكرة مؤقتة** - sessionStorage للتخزين السريع
- **ضغط تلقائي** - Gzip/Brotli على الخوادم

## 🔒 **الأمان**

- **بيانات محلية** - لا تُرسل للخوادم غير Firebase
- **HTTPS فقط** - تشفير كامل للبيانات
- **لا كوكيز** - استخدام sessionStorage فقط
- **Firebase Security** - قواعد أمان صارمة
